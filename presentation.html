MODULE 4 — DOCKER CONTAINERIZATION

Multi-Stage Docker & Non-Root Security

Lightweight OCI container packaging running via Docker Compose.

  • •Hardened Alpine Backend: Compacted image size from ~180MB (Debian) down to ~60MB.
  • •Multi-Stage Frontend: node:20-alpine build container + nginx:alpine production runtime.
  • •Non-Root Execution: Backend runs as unprivileged user appuser (10001).
  • •Docker Compose Stack: Single command orchestrates app, database, and monitoring.
Evaluation Result: 10 / 10 Points — Multi-stage + Non-root + Compose stack
MODULE 5 — CI/CD AUTOMATION

GitHub Actions Pipeline Automation

Automated builds, tests, layer caching, and GHCR registry publishing.

  • •Trigger on Push: Automatically executes on every commit to main.
  • •Parallel Execution: Pytest backend testing runs alongside Vite frontend compilation.
  • •Docker Buildx & Cache: Uses GitHub Actions layer cache (type=gha) for fast builds.
  • •Immutable SHA Tagging: Images tagged with 7-char Git commit SHAs (no mutable latest).
Evaluation Result: 15 / 15 Points — 100% Green Pipeline Run Verified
MODULE 6 — DEVSECOPS & TRIVY

Container Security & Vulnerability Gates

Aqua Security Trivy automated scanning with zero tolerated High/Critical CVEs.

  • •Trivy Security Gate: Scans both frontend and backend images in CI pipeline.
  • •Enforcement Policy: Pipeline configured to fail on HIGH or CRITICAL CVEs (exit-code: 1).
  • •Debian CVE Remediation: Eliminated 48 unpatched OS vulnerabilities by shifting to Alpine Linux.
  • •Python Packages Patched: Resolved multipart and Starlette CVEs with locked version pins.
Evaluation Result: 5 / 5 Points — Zero Actionable High/Critical Vulnerabilities
MODULE 7 — INFRASTRUCTURE AS CODE

AWS Cloud Provisioning via Terraform

Declarative multi-AZ VPC, subnets, and Amazon EKS cluster architecture.

  • •Modular HCL Configuration: Structured in terraform/ with variables & outputs.
  • •Multi-AZ Networking: Custom VPC (10.0.0.0/16) across ap-south-1a and ap-south-1b subnets.
  • •Amazon EKS 1.30 Control Plane: Managed Kubernetes with IAM cluster roles & OIDC provider.
  • •Node Group Provisioning: EC2 worker nodes using Amazon Linux 2023 (AL2023) AMI.
Evaluation Result: 15 / 15 Points — Valid Plan (15 to add) + Init + State Apply
